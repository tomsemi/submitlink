## Excluded Guide Routes

The following guide categories are intentionally not added here because they require separate workflows: business/entity claims; package managers and extension stores; GitHub Awesome PRs; media or podcast outreach; technical/community posts; long-form content syndication; design-community publishing; and Q&A/social participation.
