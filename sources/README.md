# Candidate Sources

`flaqai-free-backlink-list.md` is a verbatim candidate-list import from [`flaqai/backlink_skills`](https://github.com/flaqai/backlink_skills), with a provenance notice added above the original content.

It is licensed under MIT. The original list contains historical notes, duplicates, unavailable sites, paid listings, reciprocal-link requirements, and routes outside this skill's scope. It must never be treated as an approved queue.

Before processing an entry, apply `../references/quality-gate.md`, `../references/route-boundaries.md`, and `../references/authorization.md`. Keep no more than 10 qualified sites in a pilot batch.

`high-quality-guide-candidates.md` contains only new entries selected from the locally supplied `高质量外链获取与品牌实体构建指南.md`. All start as `not checked`; the guide's DR, dofollow, and indexing claims are not treated as current facts.
